# PR02 — типы и поля сообщений

## Основные топики

| Топик | Тип | Направление | Назначение |
|---|---|---|---|
| `/turtle1/cmd_vel` | `geometry_msgs/msg/Twist` | команда → turtlesim (подписчик: `turtlesim`) | скоростная команда для черепахи turtle1 |
| `/turtle1/pose` | `turtlesim_msgs/msg/Pose` (по выводу `ros2 topic type /turtle1/pose`) | turtlesim → наблюдатели (издатель: `turtlesim`) | текущая поза черепахи, публикуется периодически |

Тип позы выбран по фактическому выводу команды в ROS 2 Lyrical
(`turtlesim_msgs/msg/Pose`); в Jazzy тот же тип называется `turtlesim/msg/Pose`.

## geometry_msgs/msg/Twist

```
Vector3  linear
	float64 x
	float64 y
	float64 z
Vector3  angular
	float64 x
	float64 y
	float64 z
```

Сообщение задаёт скорость в свободном пространстве двумя векторами. turtlesim —
плоский симулятор, поэтому использует не все поля:

| Поле | Смысл | Использование в turtlesim |
|---|---|---|
| `linear.x` | поступательная скорость вперёд, м/с | задаёт движение вперёд/назад |
| `linear.y` | скорость влево/вправо, м/с | игнорируется (нет бокового хода) |
| `linear.z` | скорость вверх/вниз, м/с | игнорируется (плоскость XY) |
| `angular.x`, `angular.y` | крен и тангаж, рад/с | игнорируются |
| `angular.z` | угловая скорость вокруг оси Z (рыскание), рад/с | задаёт поворот против/по часовой |

В опыте использовалось `{linear: {x: 1.0}, angular: {z: 0.5}}`: движение
вперёд со скоростью 1 м/с и поворот против часовой стрелки 0.5 рад/с — что
и подтвердили позы `pose-before.txt` → `pose-after.txt` (x 5.54 → 6.51,
theta 0.0 → 0.504).

## turtlesim_msgs/msg/Pose

Поля сообщения о позе (наблюдались в `pose-*.txt`): `x`, `y` — координаты в
плоскости; `theta` — угол головы, рад; `linear_velocity`, `angular_velocity` —
текущие скорости (после одиночной команды равны 0: движение прекращается без
новых команд).
